# Car For App — Flutter Mobile App

## 📱 Stack

| الطبقة | التقنية |
|--------|---------|
| Framework | Flutter 3.x + Dart |
| Auth | Firebase Auth (Google + Email) |
| Database | Cloud Firestore (نفس المشروع الحالي) |
| Storage | Firebase Storage (بديل Base64) |
| State Management | Provider |
| Images | `image_picker` + `flutter_image_compress` → Firebase Storage |

## 🔥 Firebase Storage Setup (لازم تعمله)

### 1️⃣ فعّل Firebase Storage من الكونسول
```
Firebase Console > Build > Storage > Get Started
اختر Spark plan (مجاني)
```

### 2️⃣ القواعد (Rules)
```
rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    match /cars/{allPaths=**} {
      allow read;
      allow write: if request.auth != null;
    }
  }
}
```

### 3️⃣ في Flutter, الرفع بيبقى كده
```dart
import 'package:firebase_storage/firebase_storage.dart';

Future<String> uploadImage(File imageFile, String fileName) async {
  final ref = FirebaseStorage.instance.ref('cars/$fileName');
  await ref.putFile(imageFile);
  return await ref.getDownloadURL();
}
```
